Avoid リスト 公開パッケージ

このフォルダをそのままWebサーバーにアップロードすると、LPからAPKをダウンロードできます。

含まれるファイル:
- index.html
- styles.css
- AvoidList.apk

使い方:
1. このフォルダの中身をホスティング先へアップロードします。
2. 公開された index.html のURLをTwitterに貼ります。
3. 訪問者はページ内の「APKをダウンロード」から AvoidList.apk を入手できます。

注意:
- GitHub Pagesを使うとGitHubアカウント名がURLに出ます。
- 名前を出したくない場合は、別名義のホスティング先を使ってください。
- Google Play未公開APKなので、Android端末側で不明なアプリのインストール許可が必要です。
