How it works

使い方

01

昨日を振り返る

日付を選び、時計から時間帯を入れます。何をしていたかを残すことで、今日の判断材料になります。

02

今日しないことを選ぶ

昨日の記録から、今日はしないことをリストへ移します。代わりにすることも一緒に残せます。

03

Buyを記録する

買ったものと金額を入れます。今日、昨日、今月合計で見えるので、お金の流れも確認できます。

04

ホームで今を見る

ホームは4枚カードを横にスライドして、昨日の今ごろ、今日しないこと、Buy、発生した時間を確認します。

Install

インストール手順

  1. Androidでこのページを開きます。
  2. APKをダウンロードします。
  3. ダウンロードしたAPKを開きます。
  4. 確認が出たら、ブラウザからのインストールを許可します。
  5. もう一度APKを開いてインストールします。

Security

安全性

  • アプリ本体に外部通信処理はありません。
  • 記録データは端末内に保存します。
  • 連絡先、写真、位置情報、外部ストレージ権限は使いません。
  • 必要な権限は通知と、再起動後の通知再設定だけです。

配布メモ
